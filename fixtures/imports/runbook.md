# Rotate the courier API key

## Summary

How to rotate the API key couriers use to post scan events.

## When to use

Every 90 days, or at once when a key may have leaked.

## Steps

1. Create a new key in the admin panel.
2. Send it to couriers through the partner portal.
3. Revoke the old key after 7 days.

## Rollback

Re-enable the old key in the admin panel.

## Verify

Scan events keep arriving from every courier.
